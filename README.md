# Bemt-Hawt_Electrical
Modelo computacional integrado em MATLAB para simulação aerodinâmica e eletromecânica de uma turbina eólica de pequeno porte. Combina BEMT com correções avançadas (Shen, Glauert–Buhl, Boeing–Vertol) e um PMSG no referencial dq com controle MPPT/MPTA. Inclui dados de vento e curvas de potência de Marapanim-PA (Amazônia).
